# Hashi V1 (Historical Reference)

This directory contains the original Hashi V1 implementation (Node.js / Fastify).

It is preserved for behavioral reference only — topology mapping, DNS sync patterns, status generation lessons, and idempotent write behavior. **Do not import V1 modules into V2 code.**

V2 is a complete rewrite (.NET 10 + SvelteKit 5 + PostgreSQL). See the repository root and `docs/` for the active codebase.
